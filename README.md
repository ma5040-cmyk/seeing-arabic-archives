# Seeing Arabic Archives

Plain HTML + ES modules + Three.js. Serve locally from this folder:

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000/` to play the full opening. Use `http://localhost:8000/#cafe` to test the café directly.

The provided Rhino 3DM model is in `models/cafe.3dm`. A future export named `models/cafe.glb` will be preferred automatically.
